PNGanimatic — это веб приложение с минимальным порогом вхождения, чтобы делать простую анимацию.
Главная фишка в том, что пока вы двигаете png, приложение записывает ключевые кадры в реальном времени. 
Кстати, благодаря тому, как устроена программа, она тянет анимацию хоть в 2K и 240+FPS (проверял лично) 
(Вайбкодинг: claude sonnet 5.5 ; gemini flash 3.6)
